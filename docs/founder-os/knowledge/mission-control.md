# KB-FOUNDER-004 — Mission Control

Mission Control is the executive command center for Founder OS. It summarizes what requires Founder attention, workspace health, release readiness, recent changes, pending decisions, active risks, and recommended next actions.

## Executive Questions

1. What requires attention now?
2. Which workspaces are healthy, incomplete, blocked, or archived?
3. What changed since the last session?
4. What decisions are waiting?
5. What should happen next?

## Single Source of Truth Rule

Mission Control displays summaries and references. It does not duplicate complete workspace records or combine product knowledge across workspaces.
