# KB-FOUNDER-002 — Founder OS Architecture Reference

Founder OS is the operating system for managing independent product workspaces. Its canonical runtime is `docs/founder-os/`.

## Workspace Model

Founder OS provides Mission Control, Knowledge, Build Work, Repository Intelligence, AI Operations, reports, settings, and workspace lifecycle management.

Each product workspace remains isolated and owns its product requirements, design, assets, protocols, and implementation records.

## Layout Standard

- left workspace-aware navigation
- workspace heading and identity
- compact metrics
- main operational panel
- optional context rail
- workspace-specific command actions
- responsive desktop, tablet, and mobile behavior

## Source of Truth

GitHub is the canonical source for Founder OS architecture, governance, releases, decisions, and knowledge records.
