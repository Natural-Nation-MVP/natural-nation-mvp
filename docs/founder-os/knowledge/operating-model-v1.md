# KB-FOUNDER-005 — Founder OS Operating Model v1

Founder OS coordinates independent workspaces through a controlled operating loop:

Mission Control → Workspace Knowledge → Repository Intelligence → Build Work → AI Operations → GitHub and validation → Mission Control

## Responsibilities

| Area | Primary Founder Question | Outcome |
| --- | --- | --- |
| Mission Control | What needs attention? | Clear priorities |
| Workspace Knowledge | What does this workspace know? | Isolated trusted records |
| Repository Intelligence | What changed or is out of sync? | Verified technical state |
| Build Work | What is being built next? | Approved implementation package |
| AI Operations | Who owns the work? | Coordinated execution |
| GitHub and validation | What is official? | Canonical evidence |

## Feature Placement Rule

Every feature must identify its owning workspace, the Founder question it answers, and the action or decision it enables. Product-specific features and records must remain inside their product workspace.
